# Benchmark Results

Machine-generated evaluation results live in this directory, one file per engine:

- `<engine>.json` — full metadata per phrase (see `docs/tts-evaluation.md`)
- `<engine>.csv` — flattened table for spreadsheet/analysis use

These files are **gitignored** — they are regenerated by every benchmark run. If you
want to archive a specific run, copy the files to a git-tracked location.

The JSON payload structure:

```json
{
  "engine": "piper",
  "run_started_at": "2026-01-01T00:00:00+00:00",
  "sample_rate": 16000,
  "result_count": 48,
  "results": [
    {
      "engine": "piper",
      "model": "...",
      "voice": "...",
      "phrase_id": "speed_camera_001",
      "text": "...",
      "output_file": "benchmark/output/piper/speed_camera_001.wav",
      "success": true,
      "started_at": "...",
      "duration_seconds": 0.42,
      "audio": { "duration_seconds": 2.1, "sample_rate": 16000, "channels": 1, "sample_width_bytes": 2 },
      "error_message": null
    }
  ]
}
```

Engines that cannot run on this machine produce a result file with
`"unavailable": true` and a `reason` string — the benchmark does not fail for them.

Human evaluation scores (naturalness, pronunciation, navigation clarity) will be
added to this format in a later milestone.
